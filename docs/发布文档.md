## 🎯 项目简介

Formula4j-Plus 是一个功能强大的Java公式计算引擎，完全兼容Formula.js语法，专为后端验证前端计算结果而设计。它支持249+个内置函数，涵盖统计、数学、文本、日期、财务、工程等各个领域，同时提供灵活的扩展机制。

## ✨ 核心特性

### 1. 完全兼容Formula.js
- 支持Formula.js的所有语法特性
- 前后端使用相同的公式，确保计算结果一致
- 支持字段引用、函数嵌套、复杂表达式

### 2. 丰富的函数库（249+）
- **统计函数**: SUM, AVERAGE, MAX, MIN, COUNT, STDEV, VAR, MEDIAN, MODE等
- **数学函数**: ABS, ROUND, SQRT, POWER, EXP, LN, SIN, COS, TAN等
- **文本函数**: CONCATENATE, UPPER, LOWER, LEN, LEFT, RIGHT, MID等
- **日期函数**: TODAY, NOW, YEAR, MONTH, DAY, DATEDIF, DAYS等
- **逻辑函数**: IF, IFS, AND, OR, NOT, IFERROR等
- **财务函数**: PMT, FV, PV, RATE, NPER, NPV, IRR等
- **工程函数**: BIN2DEC, DEC2BIN, HEX2DEC, COMPLEX等
- **分布函数**: NORM.DIST, T.DIST, CHISQ.DIST等

### 3. 灵活的扩展机制
- **Java Lambda函数**: 使用Java代码快速注册自定义函数
- **JavaScript字符串函数**: 直接使用JavaScript代码定义函数
- **JavaScript文件加载**: 一次性加载整个Formula.js库
- **字段映射**: 支持menuId到enCode的灵活映射

### 4. 高性能与可靠性
- 经过优化的计算引擎
- 线程安全，支持并发计算
- 完善的错误处理机制
- 支持复杂嵌套函数

## 🚀 快速开始

### Maven依赖

```xml
<dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>2.2.0</version>
</dependency>
```

### Gradle依赖

```gradle
dependencies {
    implementation 'com.formula:formula4j-plus:2.2.0'
}
```

### 基本使用

```java
import com.formula.calculator.FormulaCalculator;
import com.alibaba.fastjson.JSONObject;

// 准备数据
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

// 计算公式
String formula = "SUM(${price}, ${quantity}) * 1.1";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 115.5
```

### 使用FormulaData

```java
import com.formula.calculator.model.FormulaData;
import com.formula.calculator.model.FieldMark;

// 构建FormulaData
FormulaData formulaData = new FormulaData();
formulaData.setTxt("SUM(单价,数量) * (1 - 折扣率)");

// 添加字段映射
List<FieldMark> marks = new ArrayList<>();
marks.add(new FieldMark("price", "单价"));
marks.add(new FieldMark("quantity", "数量"));
marks.add(new FieldMark("discount", "折扣率"));
formulaData.setMarks(marks);

// 准备数据
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);
data.put("discount", 0.1);

// 计算
Object result = FormulaCalculator.calculate(formulaData, data);
```

## 🔧 自定义函数

### Java Lambda函数

```java
FormulaCalculator.registerCustomFunction("DOUBLE", (params, data, mapping) -> {
    double value = Double.parseDouble(params.trim());
    return String.valueOf(value * 2);
});

String formula = "DOUBLE(10)";
Object result = FormulaCalculator.calculate(formula, data); // 20.0
```

### JavaScript函数

```java
String jsScript = "function(x) { return x * x; }";
FormulaCalculator.registerCustomFunction("SQUARE", "js", jsScript);

String formula = "SQUARE(5)";
Object result = FormulaCalculator.calculate(formula, data); // 25.0
```

### 一次性加载Formula.js库

```java
// 加载Formula.js库
FormulaCalculator.loadFormulaJsLibrary("file:///D:/formula.js");

// 加载后，所有函数都可以直接使用
String formula = "SUM(1, 2, 3) + ABS(-5) + SQRT(16)";
Object result = FormulaCalculator.calculate(formula, data); // 15.0
```
