# Formula4j-Plus: A Java Formula Calculation Engine

## Introduction

Formula4j-Plus is a powerful Java formula calculation engine that is fully compatible with Formula.js syntax. It's designed for backend validation of frontend calculation results.

## Key Features

- ✅ Fully compatible with Formula.js
- ✅ 249+ built-in functions
- ✅ Custom function extension
- ✅ JavaScript integration
- ✅ High performance & thread-safe

## Quick Start

### Maven
```xml
<dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>2.2.0</version>
</dependency>
```

### Usage
```java
import com.formula.calculator.FormulaCalculator;
import com.alibaba.fastjson.JSONObject;

JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

String formula = "SUM(${price}, ${quantity}) * 1.1";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 115.5
```
