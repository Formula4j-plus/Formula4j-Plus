# 字段映射

Formula4j-Plus 支持灵活的字段映射机制，可以将公式中的显示名称（menuId）映射到数据中的编码（enCode）。

## 基本概念

### menuId vs enCode

- **menuId**: 公式中使用的字段显示名称（如"单价"、"数量"）
- **enCode**: 数据 JSONObject 中使用的字段编码（如"price"、"quantity"）

### 映射关系

```
公式: SUM(单价, 数量)
      ↓
menuId: 单价 → enCode: price
menuId: 数量 → enCode: quantity
      ↓
数据: {"price": 100, "quantity": 5}
```

## 使用方式

### 方式一：使用 FormulaData

```java
import com.formula.calculator.model.FormulaData;
import com.formula.calculator.model.FieldMark;
import java.util.ArrayList;
import java.util.List;

// 构建 FormulaData
FormulaData formulaData = new FormulaData();
formulaData.setTxt("SUM(单价,数量) * (1 - 折扣率)");

// 添加字段映射
List<FieldMark> marks = new ArrayList<>();
marks.add(new FieldMark("price", "单价"));      // enCode: price, menuId: 单价
marks.add(new FieldMark("quantity", "数量"));   // enCode: quantity, menuId: 数量
marks.add(new FieldMark("discount", "折扣率")); // enCode: discount, menuId: 折扣率
formulaData.setMarks(marks);

// 准备数据（使用 enCode 作为 key）
JSONObject data = new JSONObject();
data.put("price", 100);      // 注意：使用 enCode
data.put("quantity", 5);     // 注意：使用 enCode
data.put("discount", 0.1);   // 注意：使用 enCode

// 计算
Object result = FormulaCalculator.calculate(formulaData, data);
```

### 方式二：从 JSON 创建

```java
// 前端传来的 JSON 数据
String jsonStr = "{\n" +
    "  \"txt\": \"SUM(单价,数量)\",\n" +
    "  \"marks\": [\n" +
    "    {\"enCode\": \"price\", \"menuId\": \"单价\"},\n" +
    "    {\"enCode\": \"quantity\", \"menuId\": \"数量\"}\n" +
    "  ]\n" +
    "}";

// 解析为 FormulaData
JSONObject json = JSONObject.parseObject(jsonStr);
FormulaData formulaData = FormulaData.fromJSON(json);

// 准备数据
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

// 计算
Object result = FormulaCalculator.calculate(formulaData, data);
```

## 字段引用方式

### 方式一：${fieldName}

```java
String formula = "${price} * ${quantity}";
```

### 方式二：[fieldName]

```java
String formula = "[price] * [quantity]";
```

### 方式三：直接字段名（需要映射）

```java
// 在 FormulaData 中使用 menuId
formulaData.setTxt("SUM(单价,数量)");
// 通过 marks 映射到 enCode
```

## 注意事项

### 1. 数据 key 必须使用 enCode

```java
// ✅ 正确
data.put("price", 100);  // enCode

// ❌ 错误
data.put("单价", 100);   // menuId - 不会匹配
```

### 2. 公式中使用 menuId（在 FormulaData 中）

```java
// ✅ 正确
formulaData.setTxt("SUM(单价,数量)");  // menuId

// ❌ 错误（如果使用 FormulaData）
formulaData.setTxt("SUM(price,quantity)");  // enCode - 需要直接使用字段引用
```

### 3. marks 数组必须包含所有字段

```java
// 如果公式中使用 "单价" 和 "数量"
// marks 必须包含这两个字段的映射
marks.add(new FieldMark("price", "单价"));
marks.add(new FieldMark("quantity", "数量"));
```

### 4. 字段名区分大小写

```java
// enCode 区分大小写
data.put("Price", 100);  // 与 "price" 不同
```

## 完整示例

```java
import com.formula.calculator.FormulaCalculator;
import com.formula.calculator.model.FormulaData;
import com.formula.calculator.model.FieldMark;
import com.alibaba.fastjson.JSONObject;
import java.util.ArrayList;
import java.util.List;

public class FieldMappingExample {
    public static void main(String[] args) {
        // 1. 构建 FormulaData
        FormulaData formulaData = new FormulaData();
        formulaData.setTxt("IF(销售额 >= 目标, 销售额 * 0.1, 0)");

        // 2. 添加字段映射
        List<FieldMark> marks = new ArrayList<>();
        marks.add(new FieldMark("sales", "销售额"));
        marks.add(new FieldMark("target", "目标"));
        formulaData.setMarks(marks);

        // 3. 准备数据（使用 enCode）
        JSONObject data = new JSONObject();
        data.put("sales", 10000);   // enCode: sales
        data.put("target", 8000);   // enCode: target

        // 4. 计算
        Object result = FormulaCalculator.calculate(formulaData, data);
        System.out.println("结果: " + result);  // 1000.0 (10000 * 0.1)
    }
}
```

## 调试技巧

### 打印字段映射

```java
Map<String, String> fieldMapping = new HashMap<>();
for (FieldMark mark : formulaData.getMarks()) {
    fieldMapping.put(mark.getMenuId(), mark.getEnCode());
    System.out.println("映射: " + mark.getMenuId() + " -> " + mark.getEnCode());
}
```

### 检查数据 key

```java
System.out.println("数据 keys: " + data.keySet());
// 应该包含所有 enCode
```

### 检查公式中的字段

```java
System.out.println("公式: " + formulaData.getTxt());
// 应该包含所有 menuId
```

## 常见问题

### Q: 字段值始终为 0？

A: 检查：
1. enCode 是否与数据 key 匹配
2. menuId 是否与公式中的字段名匹配
3. marks 数组是否包含所有字段

### Q: 字段映射失败？

A: 确保：
1. 字段名完全匹配（包括大小写）
2. marks 数组包含所有使用的字段
3. 数据使用 enCode 作为 key
