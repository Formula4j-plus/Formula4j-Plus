# 快速开始

5分钟快速上手 Formula4j-Plus！

## 第一步：添加依赖

在您的 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>2.2.0</version>
</dependency>
```

## 第二步：基本使用

### 简单计算

```java
import com.formula.calculator.FormulaCalculator;
import com.alibaba.fastjson.JSONObject;

// 准备数据
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

// 计算公式
String formula = "${price} * ${quantity}";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 输出: 500.0
```

### 使用函数

```java
// 使用SUM函数
String formula = "SUM(10, 20, 30)";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 输出: 60.0

// 使用IF函数
String formula2 = "IF(10 > 5, 100, 0)";
Object result2 = FormulaCalculator.calculate(formula2, data);
System.out.println("结果: " + result2); // 输出: 100.0
```

### 使用FormulaData结构

```java
import com.formula.calculator.model.FormulaData;
import com.formula.calculator.model.FieldMark;
import java.util.ArrayList;
import java.util.List;

// 构建FormulaData
FormulaData formulaData = new FormulaData();
formulaData.setTxt("SUM(单价,数量) * (1 - 折扣率)");

// 添加字段映射
List<FieldMark> marks = new ArrayList<>();
marks.add(new FieldMark("price", "单价"));
marks.add(new FieldMark("quantity", "数量"));
marks.add(new FieldMark("discount", "折扣率"));
formulaData.setMarks(marks);

// 准备数据
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);
data.put("discount", 0.1);

// 计算
Object result = FormulaCalculator.calculate(formulaData, data);
System.out.println("结果: " + result); // 输出: 450.0
```

## 第三步：更多示例

### 复杂公式

```java
// 嵌套函数
String formula = "IF(SUM(10, 20) > 25, MAX(10, 20, 30), MIN(10, 20, 30))";
Object result = FormulaCalculator.calculate(formula, data);
```

### 字符串函数

```java
// 字符串拼接
String formula = "CONCATENATE(\"Hello\", \" \", \"World\")";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 输出: Hello World
```

### 日期函数

```java
// 获取当前日期
String formula = "TODAY()";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 输出: 2025-01-XX
```
