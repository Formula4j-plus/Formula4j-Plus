# 基本使用

本文档介绍 Formula4j-Plus 的基本使用方法。

## 基本计算

### 简单表达式

```java
import com.formula.calculator.FormulaCalculator;
import com.alibaba.fastjson.JSONObject;

JSONObject data = new JSONObject();
String formula = "10 + 20";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 30.0
```

### 使用字段引用

```java
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

String formula = "${price} * ${quantity}";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 500.0
```

### 使用 FormulaData

```java
import com.formula.calculator.model.FormulaData;
import com.formula.calculator.model.FieldMark;
import java.util.ArrayList;
import java.util.List;

// 构建 FormulaData
FormulaData formulaData = new FormulaData();
formulaData.setTxt("SUM(单价,数量)");

// 添加字段映射
List<FieldMark> marks = new ArrayList<>();
marks.add(new FieldMark("price", "单价"));
marks.add(new FieldMark("quantity", "数量"));
formulaData.setMarks(marks);

// 准备数据
JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

// 计算
Object result = FormulaCalculator.calculate(formulaData, data);
System.out.println("结果: " + result); // 105.0
```

## 函数使用

### 统计函数

```java
// SUM - 求和
String formula = "SUM(10, 20, 30)";  // 60.0

// AVERAGE - 平均值
String formula = "AVERAGE(10, 20, 30)";  // 20.0

// MAX - 最大值
String formula = "MAX(10, 20, 30)";  // 30.0

// MIN - 最小值
String formula = "MIN(10, 20, 30)";  // 10.0
```

### 逻辑函数

```java
// IF - 条件判断
String formula = "IF(10 > 5, 100, 0)";  // 100.0

// AND - 逻辑与
String formula = "AND(10 > 5, 20 > 10)";  // TRUE

// OR - 逻辑或
String formula = "OR(10 < 5, 20 > 10)";  // TRUE
```

### 数学函数

```java
// ABS - 绝对值
String formula = "ABS(-10)";  // 10.0

// ROUND - 四舍五入
String formula = "ROUND(3.14159, 2)";  // 3.14

// SQRT - 平方根
String formula = "SQRT(16)";  // 4.0

// POWER - 幂运算
String formula = "POWER(2, 3)";  // 8.0
```

### 文本函数

```java
// UPPER - 转大写
String formula = "UPPER(\"hello\")";  // HELLO

// LOWER - 转小写
String formula = "LOWER(\"HELLO\")";  // hello

// LEN - 字符串长度
String formula = "LEN(\"Hello\")";  // 5

// CONCATENATE - 字符串拼接
String formula = "CONCATENATE(\"Hello\", \" \", \"World\")";  // Hello World
```

## 嵌套函数

支持函数嵌套使用：

```java
// 嵌套 IF 和 SUM
String formula = "IF(SUM(10, 20) > 25, MAX(10, 20, 30), MIN(10, 20, 30))";
Object result = FormulaCalculator.calculate(formula, data);
// 结果: 30.0 (因为 SUM(10,20)=30 > 25，所以返回 MAX(10,20,30)=30)
```

## 复杂公式

### 多条件判断

```java
// 使用 IFS
String formula = "IFS(${score} >= 90, \"优秀\", ${score} >= 60, \"及格\", \"不及格\")";
```

### 条件求和

```java
// SUMIF
String formula = "SUMIF(${range}, \">10\")";
```

### 字符串处理

```java
// 提取子字符串
String formula = "MID(\"Hello World\", 1, 5)";  // Hello

// 查找字符串
String formula = "FIND(\"World\", \"Hello World\")";  // 7
```

## 错误处理

### 捕获异常

```java
import com.formula.calculator.FormulaException;

try {
    Object result = FormulaCalculator.calculate(formula, data);
    System.out.println("结果: " + result);
} catch (FormulaException e) {
    System.err.println("公式计算失败: " + e.getMessage());
    e.printStackTrace();
}
```

### 验证结果

```java
import com.formula.calculator.FormulaUtils;

// 验证前端计算结果
double frontendResult = 30.8;
boolean verified = FormulaUtils.verify(formulaData, data, frontendResult);

if (verified) {
    System.out.println("计算结果一致");
} else {
    System.out.println("计算结果不一致");
    Object backendResult = FormulaCalculator.calculate(formulaData, data);
    System.out.println("后端结果: " + backendResult);
}
```

## 最佳实践

1. **使用 FormulaData**: 对于复杂场景，使用 FormulaData 结构更清晰
2. **字段映射**: 确保字段映射正确（menuId -> enCode）
3. **错误处理**: 始终处理可能的异常
4. **性能优化**: 避免在循环中重复解析公式
5. **数据验证**: 验证输入数据的类型和格式
