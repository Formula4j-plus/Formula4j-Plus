# 故障排除

本文档帮助您解决使用 Formula4j-Plus 时遇到的常见问题。

## 编译问题

### 问题：Maven 找不到依赖

**症状**：
```
Could not find artifact com.formula:formula4j-plus:jar:2.2.0
```

**解决方案**：
1. 检查网络连接，确保可以访问 Maven Central
2. 检查 `pom.xml` 中的版本号是否正确
3. 如果使用本地安装，确保已运行 `mvn clean install`

### 问题：Java 版本不兼容

**症状**：
```
Unsupported major.minor version 52.0
```

**解决方案**：
- 确保使用 Java 8-25 版本
- 检查 `JAVA_HOME` 环境变量
- 在 IDE 中检查项目 JDK 设置

## 运行时问题

### 问题：NoClassDefFoundError

**症状**：
```
java.lang.NoClassDefFoundError: net/objecthunter/exp4j/ExpressionBuilder
```

**解决方案**：
1. 使用 Fat JAR 版本（包含所有依赖）
2. 确保所有依赖都在 classpath 中
3. 检查 Maven 依赖是否正确下载

### 问题：VerifyError

**症状**：
```
java.lang.VerifyError: Expecting a stackmap frame at branch target
```

**解决方案**：
- 这通常与代码混淆有关
- 确保 ProGuard 配置包含 `-keepattributes StackMapTable`
- 使用未混淆的版本进行测试

### 问题：公式计算返回错误结果

**症状**：公式计算结果不正确

**解决方案**：
1. 检查公式语法是否正确
2. 检查字段名是否匹配（注意大小写）
3. 检查数据类型是否正确
4. 使用调试模式查看中间结果

```java
// 启用调试（如果有日志配置）
String formula = "SUM(${a}, ${b})";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("公式: " + formula);
System.out.println("数据: " + data);
System.out.println("结果: " + result);
```

## 功能问题

### 问题：函数未识别

**症状**：函数调用未被处理，原样返回

**解决方案**：
1. 检查函数名是否正确（注意大小写）
2. 检查函数是否在 `FunctionName` 枚举中
3. 如果是自定义函数，确保已注册

```java
// 检查函数是否注册
FormulaCalculator.registerCustomFunction("MYFUNC", (params, data, mapping) -> {
    return "result";
});
```

### 问题：字段映射失败

**症状**：字段值始终为 0 或 null

**解决方案**：
1. 检查 `enCode` 是否与数据 key 匹配
2. 检查 `menuId` 是否与公式中的字段名匹配
3. 检查 `marks` 数组是否包含所有字段

```java
// 调试字段映射
Map<String, String> fieldMapping = new HashMap<>();
for (FieldMark mark : formulaData.getMarks()) {
    fieldMapping.put(mark.getMenuId(), mark.getEnCode());
    System.out.println("映射: " + mark.getMenuId() + " -> " + mark.getEnCode());
}
```

### 问题：JavaScript 函数无法执行

**症状**：JavaScript 自定义函数返回 0 或报错

**解决方案**：
1. 检查 JavaScript 引擎是否可用（Java 15+ 需要 GraalVM）
2. 检查 JavaScript 代码语法
3. 检查参数传递是否正确

```java
// 检查 JavaScript 引擎
import javax.script.ScriptEngine;
import javax.script.ScriptEngineManager;

ScriptEngineManager manager = new ScriptEngineManager();
ScriptEngine engine = manager.getEngineByName("nashorn"); // Java 8-14
// 或
ScriptEngine engine = manager.getEngineByName("graal.js"); // Java 15+ (需要GraalVM依赖)
if (engine == null) {
    System.err.println("JavaScript 引擎不可用");
}
```

## 性能问题

### 问题：计算速度慢

**症状**：公式计算耗时过长

**解决方案**：
1. 避免在循环中重复解析公式
2. 使用字段映射缓存
3. 优化公式复杂度
4. 检查是否有不必要的函数调用

```java
// 优化：预编译公式（如果支持）
// 避免在循环中重复创建 FormulaData
FormulaData formulaData = createFormulaData();
for (JSONObject data : dataList) {
    Object result = FormulaCalculator.calculate(formulaData, data);
}
```

### 问题：内存占用高

**症状**：程序内存占用持续增长

**解决方案**：
1. 检查是否有内存泄漏
2. 清理不必要的缓存
3. 使用对象池（如果适用）
4. 检查数据量是否过大

## 集成问题

### 问题：与 Spring Boot 集成问题

**症状**：在 Spring Boot 中无法正常工作

**解决方案**：
1. 确保依赖正确添加
2. 检查自动配置冲突
3. 使用 `@Component` 或 `@Service` 封装

```java
@Service
public class FormulaService {
    public Object calculate(String formula, JSONObject data) {
        try {
            return FormulaCalculator.calculate(formula, data);
        } catch (FormulaException e) {
            // 处理异常
            throw new RuntimeException("公式计算失败", e);
        }
    }
}
```

### 问题：序列化问题

**症状**：`FormulaData` 序列化失败

**解决方案**：
1. 确保使用 Fastjson 进行序列化
2. 检查字段类型是否支持序列化
3. 使用 `@JSONField` 注解（如果需要）

```java
// 序列化
String json = JSONObject.toJSONString(formulaData);

// 反序列化
FormulaData data = JSONObject.parseObject(json, FormulaData.class);
```

## 调试技巧

### 启用详细日志

```java
// 使用 System.out.println 进行调试
System.out.println("公式: " + formula);
System.out.println("数据: " + data);
System.out.println("结果: " + result);
```

### 分步调试

```java
// 1. 检查公式解析
String formula = "SUM(${a}, ${b})";
System.out.println("原始公式: " + formula);

// 2. 检查数据
JSONObject data = new JSONObject();
data.put("a", 10);
data.put("b", 20);
System.out.println("数据: " + data);

// 3. 检查字段映射
Map<String, String> mapping = buildFieldMapping(formulaData);
System.out.println("字段映射: " + mapping);

// 4. 计算结果
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result);
```
