# 安装指南

## 系统要求

- Java 8-25 运行时（编译目标 Java 8）
- Maven 3.6+（用于构建）

## Maven 依赖

### 方式一：从 Maven Central 安装（推荐）

在您的 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>2.2.0</version>
</dependency>
```

### 方式二：从本地安装

1. 克隆项目：
```bash
git clone https://github.com/Formula4j-plus/Formula4j-Plus.git
cd formula4j-plus
```

2. 构建项目：
```bash
mvn clean install
```

3. 在您的项目中添加依赖：
```xml
<dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>2.2.0</version>
</dependency>
```

## Gradle 依赖

```gradle
dependencies {
    implementation 'com.formula:formula4j-plus:2.2.0'
}
```

## 验证安装

创建一个简单的测试类：

```java
import com.formula.calculator.FormulaCalculator;
import com.alibaba.fastjson.JSONObject;

public class TestInstallation {
    public static void main(String[] args) {
        JSONObject data = new JSONObject();
        data.put("a", 10);
        data.put("b", 20);

        String formula = "${a} + ${b}";
        Object result = FormulaCalculator.calculate(formula, data);
        System.out.println("结果: " + result); // 应该输出: 30.0
    }
}
```

如果输出 `30.0`，说明安装成功！

## 依赖说明

项目依赖以下库（会自动下载）：

- `fastjson` (1.2.83) - JSON处理
- `exp4j` (0.4.8) - 表达式计算

**注意**：如果需要在 Java 15+ 中使用 JavaScript 自定义函数，需要额外添加 GraalVM JavaScript 依赖：

```xml
<dependency>
    <groupId>org.graalvm.js</groupId>
    <artifactId>js</artifactId>
    <version>23.0.0</version>
</dependency>
<dependency>
    <groupId>org.graalvm.js</groupId>
    <artifactId>js-scriptengine</artifactId>
    <version>23.0.0</version>
</dependency>
```

## 常见问题

### Q: 找不到依赖？

A: 确保您的 Maven 配置正确，并且可以访问 Maven Central 仓库。

### Q: 版本冲突？

A: 如果与其他项目有依赖冲突，可以使用 Maven 的 `exclusions` 排除冲突的依赖。

### Q: 如何更新版本？

A: 修改 `pom.xml` 中的版本号，然后运行 `mvn clean install`。
