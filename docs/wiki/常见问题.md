# 常见问题 (FAQ)

## 一般问题

### Q: 支持哪些Java版本？

A: 编译目标为 Java 8，本地验证 Java 8 和 17；CI 配置 8、17、21。其他运行时需要实际验证，脚本能力还取决于可用引擎。

### Q: 性能如何？

A: 已提供独立 JMH 开发模块，并记录三条公式、四种路径的单机基线；它不是耗时保证。严格入口支持编译复用和有界缓存，业务性能仍需按实际数据测量，见[基准记录](../benchmark-baseline.md)。

### Q: 是否线程安全？

A: 引擎注册表在单次计算开始时固定快照，实例间状态隔离；共享脚本 eval 串行执行。调用方仍需管理输入与自定义函数的并发状态。严格编译对象不可变，可跨线程复用。

### Q: 支持哪些数据类型？

A: 兼容入口保留旧数值转换行为。严格入口支持数字、文本、布尔与 null，数值返回 BigDecimal，数字字符串需要显式 VALUE。

## 使用问题

### Q: 字段值为null时怎么办？

A: 兼容入口的算术字段按 0 处理；严格入口保留 null，算术使用 null 会报 TYPE_ERROR，缺失键报 MISSING_FIELD。

### Q: 如何验证前端计算结果？

A: 使用 `FormulaUtils.verify()` 方法：

```java
boolean verified = FormulaUtils.verify(formulaData, data, frontendResult);
```

### Q: 支持哪些函数？

A: 支持249+个函数，包括统计、数学、文本、日期、财务等各类函数。详见 [函数列表](../../src/main/java/com/formula/calculator/FunctionName.java)。

### Q: 如何添加自定义函数？

A: 有三种方式：
1. Java Lambda: `registerCustomFunction(name, function)`
2. JavaScript字符串: `registerCustomFunction(name, "js", script)`
3. JavaScript文件: `registerCustomFunctionFromFile(name, path, functionName)`

详见 [自定义函数](../../USAGE.md)。

## 技术问题

### Q: 如何处理嵌套函数？

A: Formula4j-Plus 自动处理嵌套函数，支持多层嵌套。例如：

```java
String formula = "IF(SUM(10, 20) > 25, MAX(10, 20), MIN(10, 20))";
```

### Q: 支持哪些表达式语法？

A: 支持标准的数学表达式语法：
- 算术运算: `+`, `-`, `*`, `/`, `%`
- 比较运算: `>`, `<`, `>=`, `<=`, `==`, `!=`
- 逻辑运算: `AND`, `OR`, `NOT`
- 函数调用: `FUNCTION_NAME(param1, param2)`

### Q: 如何处理字符串？

A: 字符串需要用双引号括起来，例如：

```java
String formula = "CONCATENATE(\"Hello\", \"World\")";
```

### Q: JavaScript引擎支持情况？

A:
- Java 8-14: 使用 Nashorn 引擎（内置，开箱即用）
- Java 15-25: 支持 GraalVM JavaScript 引擎（需要额外添加依赖，可选）

## 错误处理

### Q: 遇到 `FormulaException` 怎么办？

A: `FormulaException` 是公式计算异常，通常表示公式语法错误或参数错误。请检查：
1. 公式语法是否正确
2. 字段名是否正确
3. 参数类型是否匹配

### Q: 遇到 `NoClassDefFoundError` 怎么办？

A: 这通常表示依赖未正确打包。使用 Fat JAR 版本（`formula4j-plus-*-fat.jar`）可以解决此问题。

### Q: 遇到 `VerifyError` 怎么办？

A: 这通常与代码混淆有关。确保使用正确的 ProGuard 配置，包含 `-keepattributes StackMapTable`。

## 集成问题

### Q: 如何与Spring Boot集成？

A: 可以直接使用，无需特殊配置：

```java
@Service
public class FormulaService {
    public Object calculate(String formula, JSONObject data) {
        return FormulaCalculator.calculate(formula, data);
    }
}
```

### Q: 如何与前端Formula.js保持一致？

A: Formula4j-Plus 采用 Formula.js 风格语法，具体边界见行为契约 语法，可以直接使用前端相同的公式。

## 性能优化

### Q: 如何提高计算性能？

A:
1. 避免在循环中重复解析公式
2. 使用字段映射缓存
3. 对于复杂公式，考虑预编译

### Q: 内存占用如何？

A: Formula4j-Plus 内存占用很小，主要取决于：
- 数据量大小
- 公式复杂度
- 缓存策略
