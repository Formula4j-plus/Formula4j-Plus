# FormulaData 自定义字段名结构使用指南

## 概述

`FormulaData` 类现在支持使用不同的字段名结构，而不仅仅局限于 `txt` 和 `marks`。您可以使用 `formula`/`fields`、`expression`/`fieldMarks` 等任意字段名组合。

## 功能特性

- ✅ **支持自定义字段名**：可以指定公式文本和字段标记数组的字段名
- ✅ **自动回退机制**：如果指定字段不存在，会自动尝试常见的字段名
- ✅ **字段名映射配置**：支持通过 Map 配置字段名映射
- ✅ **向后兼容**：完全兼容原有的 `txt`/`marks` 结构

## 使用方式

### 1. 默认结构（向后兼容）

原有的 `txt` 和 `marks` 结构仍然可以正常使用：

```java
String jsonStr = "{\n" +
    "  \"txt\": \"SUM(字段1,字段2)\",\n" +
    "  \"marks\": [\n" +
    "    {\"enCode\": \"field1\", \"menuId\": \"字段1\"},\n" +
    "    {\"enCode\": \"field2\", \"menuId\": \"字段2\"}\n" +
    "  ]\n" +
    "}";

JSONObject json = JSONObject.parseObject(jsonStr);
FormulaData formulaData = FormulaData.fromJSON(json);
```

### 2. 自定义字段名

使用 `formula` 和 `fields` 作为字段名：

```java
String jsonStr = "{\n" +
    "  \"formula\": \"SUM(单价,数量)\",\n" +
    "  \"fields\": [\n" +
    "    {\"enCode\": \"price\", \"menuId\": \"单价\"},\n" +
    "    {\"enCode\": \"quantity\", \"menuId\": \"数量\"}\n" +
    "  ]\n" +
    "}";

JSONObject json = JSONObject.parseObject(jsonStr);
FormulaData formulaData = FormulaData.fromJSON(json, "formula", "fields");
```

### 3. 使用 expression 和 fieldMarks

```java
String jsonStr = "{\n" +
    "  \"expression\": \"字段1 * 字段2\",\n" +
    "  \"fieldMarks\": [\n" +
    "    {\"enCode\": \"f1\", \"menuId\": \"字段1\"},\n" +
    "    {\"enCode\": \"f2\", \"menuId\": \"字段2\"}\n" +
    "  ]\n" +
    "}";

JSONObject json = JSONObject.parseObject(jsonStr);
FormulaData formulaData = FormulaData.fromJSON(json, "expression", "fieldMarks");
```

### 4. 使用字段名映射配置

通过 Map 配置字段名映射：

```java
String jsonStr = "{\n" +
    "  \"formulaText\": \"AVERAGE(分数1,分数2,分数3)\",\n" +
    "  \"fieldList\": [\n" +
    "    {\"enCode\": \"score1\", \"menuId\": \"分数1\"},\n" +
    "    {\"enCode\": \"score2\", \"menuId\": \"分数2\"},\n" +
    "    {\"enCode\": \"score3\", \"menuId\": \"分数3\"}\n" +
    "  ]\n" +
    "}";

JSONObject json = JSONObject.parseObject(jsonStr);

// 配置字段名映射
Map<String, String> fieldMapping = new HashMap<>();
fieldMapping.put("formula", "formulaText");  // 逻辑字段名 -> 实际字段名
fieldMapping.put("marks", "fieldList");

FormulaData formulaData = FormulaData.fromJSON(json, fieldMapping);
```

### 5. 自动回退机制

如果指定的字段名不存在，系统会自动尝试常见的字段名：

- **公式文本字段**：优先尝试 `txt`，然后是 `formula`，最后是 `expression`
- **字段标记数组**：优先尝试 `marks`，然后是 `fields`，最后是 `fieldMarks`

```java
String jsonStr = "{\n" +
    "  \"formula\": \"MAX(值1,值2)\",\n" +
    "  \"marks\": [\n" +
    "    {\"enCode\": \"v1\", \"menuId\": \"值1\"},\n" +
    "    {\"enCode\": \"v2\", \"menuId\": \"值2\"}\n" +
    "  ]\n" +
    "}";

JSONObject json = JSONObject.parseObject(jsonStr);

// 即使指定了不存在的字段名，也会自动回退到 formula 和 marks
FormulaData formulaData = FormulaData.fromJSON(json, "nonExistent", "alsoNonExistent");
// 仍然可以正确解析，因为会自动回退
```

## 完整示例

```java
import com.alibaba.fastjson.JSONObject;
import com.formula.calculator.FormulaCalculator;
import com.formula.calculator.model.FormulaData;
import java.util.HashMap;
import java.util.Map;

public class CustomStructureExample {
    public static void main(String[] args) {
        // 示例1：使用默认结构
        String json1 = "{\n" +
            "  \"txt\": \"SUM(字段1,字段2)\",\n" +
            "  \"marks\": [\n" +
            "    {\"enCode\": \"f1\", \"menuId\": \"字段1\"},\n" +
            "    {\"enCode\": \"f2\", \"menuId\": \"字段2\"}\n" +
            "  ]\n" +
            "}";
        
        JSONObject jsonObj1 = JSONObject.parseObject(json1);
        FormulaData data1 = FormulaData.fromJSON(jsonObj1);
        
        JSONObject values1 = new JSONObject();
        values1.put("f1", 10);
        values1.put("f2", 20);
        Object result1 = FormulaCalculator.calculate(data1, values1);
        System.out.println("结果1: " + result1); // 输出: 30.0
        
        // 示例2：使用自定义字段名
        String json2 = "{\n" +
            "  \"formula\": \"AVERAGE(分数1,分数2,分数3)\",\n" +
            "  \"fields\": [\n" +
            "    {\"enCode\": \"s1\", \"menuId\": \"分数1\"},\n" +
            "    {\"enCode\": \"s2\", \"menuId\": \"分数2\"},\n" +
            "    {\"enCode\": \"s3\", \"menuId\": \"分数3\"}\n" +
            "  ]\n" +
            "}";
        
        JSONObject jsonObj2 = JSONObject.parseObject(json2);
        FormulaData data2 = FormulaData.fromJSON(jsonObj2, "formula", "fields");
        
        JSONObject values2 = new JSONObject();
        values2.put("s1", 80);
        values2.put("s2", 90);
        values2.put("s3", 100);
        Object result2 = FormulaCalculator.calculate(data2, values2);
        System.out.println("结果2: " + result2); // 输出: 90.0
        
        // 示例3：使用字段名映射配置
        String json3 = "{\n" +
            "  \"expressionText\": \"字段1 * 字段2\",\n" +
            "  \"fieldArray\": [\n" +
            "    {\"enCode\": \"x\", \"menuId\": \"字段1\"},\n" +
            "    {\"enCode\": \"y\", \"menuId\": \"字段2\"}\n" +
            "  ]\n" +
            "}";
        
        JSONObject jsonObj3 = JSONObject.parseObject(json3);
        Map<String, String> mapping = new HashMap<>();
        mapping.put("formula", "expressionText");
        mapping.put("marks", "fieldArray");
        
        FormulaData data3 = FormulaData.fromJSON(jsonObj3, mapping);
        
        JSONObject values3 = new JSONObject();
        values3.put("x", 5);
        values3.put("y", 6);
        Object result3 = FormulaCalculator.calculate(data3, values3);
        System.out.println("结果3: " + result3); // 输出: 30.0
    }
}
```

## 支持的字段名组合

### 公式文本字段名
- `txt`（默认）
- `formula`
- `expression`
- 或任意自定义字段名

### 字段标记数组字段名
- `marks`（默认）
- `fields`
- `fieldMarks`
- 或任意自定义字段名

## API 参考

### FormulaData 字段名相关方法

| 方法 | 说明 |
|------|------|
| `fromJSON(JSONObject json)` | 使用默认字段名（txt, marks） |
| `fromJSON(JSONObject json, String formulaKey, String marksKey)` | 指定公式文本和字段标记数组的字段名 |
| `fromJSON(JSONObject json, Map<String, String> fieldMapping)` | 使用字段名映射配置 |

### 字段名映射配置

`fieldMapping` Map 的 key 为逻辑字段名：
- `"formula"` - 对应公式文本字段
- `"marks"` - 对应字段标记数组字段

value 为 JSON 中的实际字段名。

## 注意事项

1. **向后兼容**：原有的 `txt`/`marks` 结构完全兼容，无需修改现有代码
2. **自动回退**：如果指定字段不存在，会自动尝试常见字段名
3. **字段名区分大小写**：字段名是区分大小写的
4. **空值处理**：如果所有尝试的字段名都不存在，公式文本和字段标记数组会为 null 或空列表

## 使用场景

- **多系统集成**：不同系统使用不同的字段名结构
- **API 版本兼容**：支持新旧版本的 API 数据结构
- **灵活配置**：根据配置动态指定字段名
- **第三方集成**：适配第三方系统的数据结构
