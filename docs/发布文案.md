## 📝 详细介绍（适合技术博客、文档站）

### 项目概述

**Formula4j-Plus** 是一个功能强大的Java公式计算引擎，完全兼容Formula.js语法，专为后端验证前端计算结果而设计。它支持249+个内置函数，涵盖统计、数学、文本、日期、财务、工程等各个领域，同时提供灵活的扩展机制，支持自定义函数和JavaScript集成。

### 核心特性

#### 1. 完全兼容Formula.js
- 支持Formula.js的所有语法特性
- 前后端使用相同的公式，确保计算结果一致
- 支持字段引用、函数嵌套、复杂表达式

#### 2. 丰富的函数库
- **统计函数**：SUM, AVERAGE, MAX, MIN, COUNT, STDEV, VAR等
- **数学函数**：ABS, ROUND, SQRT, POWER, SIN, COS, TAN等
- **文本函数**：CONCATENATE, UPPER, LOWER, LEN, LEFT, RIGHT等
- **日期函数**：TODAY, NOW, YEAR, MONTH, DAY, DATEDIF等
- **逻辑函数**：IF, IFS, AND, OR, NOT等
- **财务函数**：PMT, FV, PV, NPV, IRR等
- **工程函数**：BIN2DEC, HEX2DEC, COMPLEX等
- **分布函数**：NORM.DIST, T.DIST, CHISQ.DIST等

#### 3. 灵活的扩展机制
- **Java Lambda函数**：使用Java代码快速注册自定义函数
- **JavaScript字符串函数**：直接使用JavaScript代码定义函数
- **JavaScript文件加载**：一次性加载整个Formula.js库，所有函数可用
- **字段映射**：支持menuId到enCode的灵活映射

#### 4. 高性能与可靠性
- 经过优化的计算引擎，支持大量并发计算
- 线程安全，可在多线程环境中使用
- 完善的错误处理和异常机制
- 支持复杂嵌套函数和递归调用

### 使用场景

1. **后端验证前端计算结果**
   - 前端使用Formula.js计算，后端使用Formula4j-Plus验证
   - 确保数据一致性和准确性

2. **报表系统**
   - 动态公式计算
   - 数据汇总和分析
   - 复杂业务逻辑计算

3. **数据分析平台**
   - 统计计算
   - 数据转换
   - 公式化数据处理

4. **企业应用系统**
   - 财务计算
   - 工程计算
   - 业务规则引擎

### 快速开始

```xml
<dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>2.2.0</version>
</dependency>
```

```java
import com.formula.calculator.FormulaCalculator;
import com.alibaba.fastjson.JSONObject;

JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

String formula = "SUM(${price}, ${quantity}) * 1.1";
Object result = FormulaCalculator.calculate(formula, data);
System.out.println("结果: " + result); // 115.5
```
