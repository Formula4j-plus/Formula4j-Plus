功能特性

249+ 函数支持

支持统计、数学、文本、日期、财务、工程等各类函数，完全兼容 Formula.js 库。

自定义函数扩展

支持 Java Lambda、JavaScript 字符串和文件三种方式注册自定义函数，灵活扩展。

Formula.js 兼容

完全兼容 Formula.js 语法，可以直接使用前端相同的公式，确保计算结果一致。

字段映射

支持 menuId 到 enCode 的字段映射，完美适配前端数据结构。

结果验证

提供前端计算结果验证功能，支持自定义误差范围。

高性能

经过优化，可以高效处理大量计算，支持复杂嵌套函数。

快速开始

1. 添加依赖

<dependencies>
  <dependency>
    <groupId>com.formula</groupId>
    <artifactId>formula4j-plus</artifactId>
    <version>3.0.0</version>
  </dependency>
</dependencies>

2. 基本使用

import com.alibaba.fastjson.JSONObject;
import com.formula.calculator.FormulaCalculator;

JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);

String formula = "${price} * ${quantity}";
Object result = FormulaCalculator.calculate(formula, data);

System.out.println("结果: " + result);
// 输出: 500

3. 使用函数

String sumFormula = "SUM(10, 20, 30)";
Object sumResult = FormulaCalculator.calculate(sumFormula, data);
// 结果: 60.0

String ifFormula = "IF(10 > 5, 100, 0)";
Object ifResult = FormulaCalculator.calculate(ifFormula, data);
// 结果: 100

使用示例

使用 FormulaData 结构

import com.alibaba.fastjson.JSONObject;
import com.formula.calculator.FormulaCalculator;
import com.formula.calculator.model.FieldMark;
import com.formula.calculator.model.FormulaData;

import java.util.ArrayList;
import java.util.List;

FormulaData formulaData = new FormulaData();
formulaData.setTxt("单价 * 数量 * (1 - 折扣率)");

List<FieldMark> marks = new ArrayList<>();
marks.add(new FieldMark("price", "单价"));
marks.add(new FieldMark("quantity", "数量"));
marks.add(new FieldMark("discount", "折扣率"));
formulaData.setMarks(marks);

JSONObject data = new JSONObject();
data.put("price", 100);
data.put("quantity", 5);
data.put("discount", 0.1);

Object result = FormulaCalculator.calculate(formulaData, data);
// 结果: 450.0

自定义函数

FormulaCalculator.registerCustomFunction("DOUBLE", (params, data, mapping) -> {
    double value = Double.parseDouble(params.trim());
    return String.valueOf(value * 2);
});

Object result = FormulaCalculator.calculate("DOUBLE(10)", new JSONObject());
// 结果: 20.0

一次性加载 Formula.js 库

// 仅在你需要扩展 Formula.js 场景时加载
FormulaCalculator.loadFormulaJsLibrary("file:///D:/formula.js");

JSONObject data = new JSONObject();
String formula = "SUM(1, 2, 3) + ABS(-5) + SQRT(16)";
Object result = FormulaCalculator.calculate(formula, data);

// 结果: 15.0
